# Zenavo Homebrew tap

```sh
brew install zenavo-app/tap/zenavo
```

Installs the [Zenavo CLI](https://github.com/Zenavo-App/zenavo-cli) on macOS and Linux. `brew upgrade zenavo` updates it.

`Formula/zenavo.rb` is written by the zenavo-cli release workflow for each release, from the release's own binaries and `SHA256SUMS`. Changes made here by hand are overwritten; open issues and pull requests in [zenavo-cli](https://github.com/Zenavo-App/zenavo-cli) instead.

Other ways to install: [docs.zenavo.app/cli](https://docs.zenavo.app/cli).
